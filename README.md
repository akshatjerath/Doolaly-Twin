# doolally-twin
EA 2 digital twin of Doolally Taproom, Khar. Start Claude Code in this folder and paste the brief from `docs/claude-code-prompt.md`.

View locally with `npm install` then `npm run dev`. VS Code Live Preview or opening `index.html` directly will not work: it serves static files only, so the TypeScript modules and `?raw` imports never load.

reference/ holds the inputs (photos, street view, layout sketch and notes, evidence register, visit log, Gemini prototype).
docs/ holds the brief, the Gemini audit and open questions.
